# Vidanjări Iași – Service Website

A responsive service website developed for MIHOT SRL, focused on promoting waste removal and related services in Iași, Romania.

The project was designed as a real-world business website, with a strong focus on accessibility, local SEO, mobile usability and converting visitors into customer inquiries.

## Live Website

The website is currently deployed and used by MIHOT SRL:

https://vidanjariiasi.mihot.ro/

## Features

- Responsive and mobile-friendly design
- Service presentation sections
- Direct phone call integration
- WhatsApp contact integration
- Customer reviews section
- Image gallery
- Frequently Asked Questions (FAQ)
- Clear call-to-action elements
- Contact and company information
- Local SEO optimization
- Search engine sitemap
- Robots.txt configuration
- Structured content for search engines

## Technologies Used

- HTML5
- CSS3
- Responsive Web Design
- SEO optimization
- Schema.org structured data

## SEO

The website includes several technical SEO elements designed to improve search engine visibility:

- Local business structured data
- Meta information
- Sitemap.xml
- Robots.txt
- Semantic HTML structure
- Mobile-friendly layout
- Local service-oriented content

## Project Structure

- `index.html` — website structure and content
- `assets.css` — styling and responsive layout
- `images/` — optimized website images
- `favicon.svg` — website favicon
- `sitemap.xml` — search engine sitemap
- `robots.txt` — crawler configuration

## Purpose

The project was created as a real-world website for a local service business, with the goal of providing customers with clear information about available services and making it easy to contact the company by phone or WhatsApp.
